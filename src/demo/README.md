# demo · 可运行的最小 MVP

> 双击 `mvp-demo.html` 即可运行，五个页签：业务工作台 / 知识和图谱 / 证据与引用 / 执行与审计 / 场景评估。
> 零依赖：不需要 Python、不需要网络、不需要模型 key。

## 两个文件

| 文件 | 说明 |
|---|---|
| `mvp-demo.html` | **零依赖版**。数据内置（20 笔合成业务 + 49 条知识 + 89 节点图谱），双击就开 |
| `index.html` | **连后端版**。先起 `uvicorn app:app --port 8010 --app-dir src/safety_backend`，打开后在左上角把后端地址填 `http://127.0.0.1:8010` |

## 两者区别（演示时要说清）

- 零依赖版：数据是打包进去的快照，**改 json 不会变**，适合没环境时兜底；
- 连后端版：所有数据实时从接口取（`/api/kb` `/api/graph` `/api/search` `/api/run`），**真跑**。

## 三条核心演示路径

1. **业务编排**：选 `CS-0001` 跑一笔 → 三步轨迹 → `pending_confirm` → 草稿带引用 K26/K27；
2. **脏数据**：选缺照片元数据那笔 → 卡在「资料不足」转人工，不猜补、不销项；
3. **知识与图谱**：输入 `K22` + 一跳 → 只剩 8 个邻居；问答返回带 5 条引用。
